# Two Lines of Morning Light

Entry for the make.fun competition `u-gudril-cool-two-lines-of-morning-light-ade94fc5` — a single two-line micro poem about light and morning.

Bounty page: https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5

## The poem

> Light comes through the keyhole first,
> and the whole house learns to breathe.

## How it runs

`main.ts` (Node 22, standard library only) writes the poem to `/output/entry.txt` — 77 characters, two lines, one image of light arriving, the second line opening it.

Run locally:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
